# Zero-to-Hero AI Infrastructure — Selected Labs

This folder preserves the useful parts of an **external introductory course** covering AI infrastructure fundamentals. It is one learning source in the wider repository, not the repository’s main project and not work originally authored by me.

> [!IMPORTANT]
> Original source, author, and license details still need to be recorded here. Until then, do not assume the repository-level Apache 2.0 license applies to this course material.

## How to use this repo

* Each populated numbered folder contains one retained lab in its `README.md`.
* Numbering follows the original course, so gaps are expected.
* Omitted sessions were intentionally skipped because they appeared repetitive, low-value, or outside the useful learning path.
* This is a curated introduction, not a completion checklist.
