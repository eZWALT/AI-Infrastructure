# Zero-to-Hero AI Infrastructure Course

A hands-on, lab-driven journey from Linux basics to production-grade AI infrastructure. Each session is a self-contained lab with goals, step-by-step instructions, and verification steps.

## How to use this repo

* Each numbered folder is one lab session; every lab lives in its folder's `README.md`.
* Labs build on each other: foundations first, then serving, observability, MLOps, and finally advanced topics.
* Empty/unfinished sessions are listed below and will be filled in as the course progresses.
